# Object-Oriented Programming (OOP)
- 4 Core Pillars:
  1. Encapsulation: Bundling data and methods, restricting direct access via access modifiers.
  2. Abstraction: Hiding internal complexity and exposing clean, stable interfaces.
  3. Inheritance: Reusing code and forming IS-A hierarchies.
  4. Polymorphism: Ability of different classes to respond to the same message (method overloading, overriding, duck typing).
- SOLID Principles:
  - Single Responsibility Principle (SRP)
  - Open/Closed Principle (OCP)
  - Liskov Substitution Principle (LSP)
  - Interface Segregation Principle (ISP)
  - Dependency Inversion Principle (DIP)
