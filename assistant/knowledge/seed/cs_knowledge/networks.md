# Computer Networks
- OSI 7-Layer Model: Physical, Data Link, Network, Transport, Session, Presentation, Application.
- TCP/IP Suite: Link, Internet (IP), Transport (TCP/UDP), Application (HTTP, DNS, SSH).
- TCP vs UDP: TCP is connection-oriented, reliable with 3-way handshake and flow/congestion control; UDP is connectionless, low-latency, best-effort.
- HTTP / HTTPS: Stateless protocol, TLS/SSL handshake for encryption, HTTP/1.1 vs HTTP/2 multiplexing vs HTTP/3 (QUIC).
