# Operating Systems (OS)
- Processes & Threads: A process is an executing program instance with isolated memory; threads share process address space.
- CPU Scheduling: FCFS, SJF, Round Robin, Priority Scheduling, Multilevel Queue.
- Concurrency & Synchronization: Race conditions, Mutex locks, Semaphores, Monitors, Deadlocks (Mutual exclusion, Hold & wait, No preemption, Circular wait).
- Memory Management: Paging, Segmentation, Virtual Memory, Page replacement algorithms (FIFO, LRU, Optimal), Thrashing.
- Storage & File Systems: Inodes, FAT, NTFS, Disk scheduling (SSTF, SCAN, C-SCAN).
