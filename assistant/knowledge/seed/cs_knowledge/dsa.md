# Data Structures and Algorithms (DSA)
- Arrays: Contiguous memory allocation, O(1) random access by index, O(N) insertion/deletion.
- Linked Lists: Nodes linked by pointers, O(1) prepend/append (with tail pointer), O(N) access.
- Stacks & Queues: LIFO (Stack) and FIFO (Queue), essential for DFS and BFS traversals.
- Hash Tables: Average O(1) lookup, insert, delete; handles collisions via chaining or open addressing.
- Binary Search: Requires sorted array, O(log N) search time complexity.
- Trees & Graphs: Binary Search Trees (BST), AVL/Red-Black balanced trees, Heaps (priority queues), Graphs represented via adjacency lists or matrices.
- Sorting: Merge Sort O(N log N) stable, Quick Sort O(N log N) avg O(N^2) worst in-place, Heap Sort O(N log N) in-place.
